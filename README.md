## ✨ 简介



**飞行之羽** 是一款网易基岩版 Minecraft 模组，添加了一系列羽翼胸甲装备。穿戴即可获得**创造模式飞行能力**，更有多种进阶羽翼提供不同的战斗与移动增益。



***



## 🎮 物品一览



| 羽翼           | 物品ID                          | 耐久  | 核心效果          | 修复材料 | 修复比例 |
| ------------ | ----------------------------- | --- | ------------- | ---- | ---- |
| **飞行之羽**     | `fly_feather:fly_feather`     | 432 | 创造飞行 + 缓降     | 羽毛   | 25%  |
| ⚡ **迅捷之羽**   | `fly_feather:swift_feather`   | 432 | 速度 V + 跳跃 III | 兔子脚  | 75%  |
| 🛡️ **不朽之羽** | `fly_feather:eternal_feather` | 更高  | 下界合金升级版       | 对应材料 | 25%  |
| 🌑 **末影之羽**  | `fly_feather:ender_feather`   | -   | 暗黑风格 + 维度增益   | 末影珍珠 | 25%  |



> 💡 所有羽翼均装备于**胸甲槽位**，使用 `netease:armor` 组件实现。

## 🔧 修复系统



本模组采用**脚本实现**自定义修复（网易已移除假日创作者实验性玩法，无法使用 JSON 组件修复）：



* **手持修复**：手持对应材料，长按/右键即可消耗经验修复羽翼



* **命令修复**：使用 `/修复羽翼` 命令直接修复



* **经验消耗**：根据修复比例消耗 1\~3 级经验



| 羽翼   | 修复材料 | 单次修复比例 |
| ---- | ---- | ------ |
| 飞行之羽 | 羽毛   | 25%    |
| 不朽之羽 | 羽毛   | 25%    |
| 末影之羽 | 末影珍珠 | 25%    |
| 迅捷之羽 | 兔子脚  | 75%    |

## 📦 安装方法



### 方式一：直接导入（推荐）



1. 下载最新版本的 `.mcaddon` 文件
2. 使用 Minecraft 基岩版打开文件，自动导入
3. 在世界设置中启用该行为包和资源包



### 方式二：手动安装



1. 将 `behavior_pack` 复制到：



   ```
   /games/com.mojang/behavior_packs/
   ```
2. 将 `resource_pack` 复制到：



   ```
   /games/com.mojang/resource_packs/
   ```
3. 在游戏中启用对应的包
