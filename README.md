## ✨ 简介




**飞行之羽** 是一款网易基岩版 Minecraft 模组，添加了一系列羽翼胸甲装备。穿戴即可获得**创造模式飞行能力**，更有多种进阶羽翼提供不同的战斗与移动增益。




网易模组中心组件码：1581436




**网易模组开源计划**

## 🎮 物品一览




| 羽翼       | 物品ID                          | 耐久   | 护甲 | 韧性 | 击退抗性 | 附魔能力 | 修复材料 | 修复比例 |
| -------- | ----------------------------- | ---- | -- | -- | ---- | ---- | ---- | ---- |
| **飞行之羽** | `fly_feather:fly_feather`     | 432  | 0  | 0  | 0    | 0    | 羽毛   | 25%  |
| **迅捷之羽** | `fly_feather:swift_feather`   | 432  | 0  | 0  | 0    | 0    | 兔子脚  | 75%  |
| **不朽之羽** | `fly_feather:eternal_feather` | 2651 | 7  | 2  | 0.1  | 4    | 幻翼膜  | 25%  |
| **末影之羽** | `fly_feather:ender_feather`   | 1296 | 0  | 0  | 0    | 0    | 龙息   | 25%  |




> 💡 所有羽翼均装备于**胸甲槽位**（`armor_slot: 1`），使用 `netease:armor` 组件实现。

## 🔧 修复系统




本模组采用**脚本实现**自定义修复（我不会铁砧修复，如果有会的欢迎交流）：




* **手持修复**：手持对应材料，长按/右键即可消耗经验修复羽翼




* **经验消耗**：根据修复比例消耗 1\~2 级经验




| 羽翼   | 修复材料 | 单次修复比例 |
| ---- | ---- | ------ |
| 飞行之羽 | 羽毛   | 25%    |
| 不朽之羽 | 幻翼膜  | 25%    |
| 末影之羽 | 末影珍珠 | 25%    |
| 迅捷之羽 | 兔子脚  | 75%    |
